# Скорость обновления SSD1683 на WeAct Studio 4.2"

Первое обновление после запуска всегда идёт в режиме полного обновления 0x22 (0xF7), занимает примерно 2.9 секунды.
Последующие обновления производятся в режиме частичного обновления.

Стандартное частичное обновление 0x22 (0xFF) занимает 0.440 секунды.

Частичное обновление без остановки аналоговой части и генератора цифровой части 0x22 (0xFC) выполняется быстрее, и составляет 0.360 секунды.

Наилучшая скорость обновления была достигнута при использовании 0x20 (0xDC), т.е. без чтения температуры и без остановки аналоговой части и генератора цифровой части.
Примерное время обновления составляет 0.355 секунды.

Попытка не активировать запуск генератора цифровой части и аналоговой части если они уже были запущены и не отключен ранее успехом не увенчалась, обновление не выполняется.

Можно съэкономить порядка 1 миллисекунды на чтении LUT из OTP во время обновления экрана.
Для этого нужно сначала установить режим 0xD8 командой 0x22 и выполнить команду 0x20.
После можно использовать режим 0xCC для обновления.
Внимание: режим обновления, указываемый битом D3 требуется указывать одинаковым и для загрузки LUT и для последующего обновления.

Можно уменьшить время на раскачку аналоговой части с использование команды 0x0C, если последний байт установить в 0x00 вместо 0x0F.
Однако, оказалось возможно не требовать запуск генератора и аналоговой части при каждом обновлении.

Если выполнить запуск генератора, аналоговой части, чтение LUT в режиме частичного обновления (команда 0x22 с параметром 0xD8, после команда 0x20);
а в посделедствии задать режим обновления командой 0x22 с параметром 0x0C, то время частичного обновления снижается до 0.277 секунды!
Никакие изменения процедур раскачки и LUT при этом не требуются.


## Параметр команды 0x22

Bit	Mask	Meaning
D7	0x80	Enable clock
D6	0x40	Enable analog power
D5	0x20	Load temperature value
D4	0x10	Load LUT from OTM
D3	0x08	Select mode: 1 = black/white (differential partial refresh), 0 = three-color (full refresh)
D2	0x04	Execute display waveform
D1	0x02	Disable analog power afterward
D0	0x01	Disable clock afterward
